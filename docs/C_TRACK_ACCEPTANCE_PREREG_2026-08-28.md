# C 轨经济验收预注册（2026-08-28）

项目：`fusion-factor-pipeline`
日期：2026-08-28
性质：预注册文件。登记后只允许执行一次验收运行；任何条款修改必须发生在运行之前并留痕，运行之后本文档只读。不构成生产批准、实盘授权或收益承诺。

## 一、验收对象

- 冻结池：`config/factor_pool_b2_frozen_2026-08-28.json`（37 因子，frozen_for_one_shot_evaluation → 本验收为同一冻结的后续经济环节，不构成因子清单变更）。
- 排序分来源：**huber_b2_neutral_rank 单模型**（LGBMRegressor huber，`y_neutral_rank20_b2`，种子 42/43/44 集成）。
  - 预注册理由：evaluation 中中性线全面更强（HAC IC_IR 0.393 vs 0.255；各块胜率更高）；raw 线在确认 v2 仅以 0.00035 IC 余量过线，为弱腿。raw 线分数只作对照附录，不参与验收判定。
- 训练/预测方式：与 evaluation 完全一致——selection 期（2023-06-30..2024-09-12）训练一次，对 evaluation 期（2024-10-22..2025-12-31）预测一次。不重新训练、不重估参数。

## 二、组合构建规则（预先固定）

1. 域：B2 逐日 universe（与训练/评估同一定义，含非 ST、上市满一年、ADV20≥200 万过滤）。
2. 每个交易日，按冻结分升序排名，**剔除底部 10%**（冻结配置 `bottom_exclusion_fraction = 0.1`）。
3. 其余成分等权。建仓 T+1 开盘价，持有 20 个交易日，T+20 收盘出场（与标签定义一致）；每日到期的队列滚动再平衡，重叠队列等分资金。
4. 持有期内个股出现以下情形的处理（预先固定，不做事后择优）：
   - 停牌：冻结持仓至复牌，复牌后按原队列计划出场；
   - 新戴帽 ST：不作中途剔除（信号的任务就是提前识别它们，中途剔除等于替信号作弊）；
   - 退市：按可获得的最后价格结算，记为实际损失；
   - 涨跌停无法成交：顺延到可成交日，以实际成交价记账。

## 三、成本模型

- 基准情形：双边各 0.1%（佣金+印花税近似）+ 单边 0.1% 滑点，即单次完整买卖往返 0.4%。
- 敏感性：0.5×、1×、2×、3× 成本四档，报告各档净超额；通过判定基于 1×，存活判定基于 2×。

## 四、基准与对照

- **主基准：B2 域等权组合**（同构建规则、不剔除）。C 轨的超额定义为"剔除 vs 不剔除"，这是本策略的诚实对照。
- 附录对照：中证 1000、中证 2000、上证指数（仅描述性，不作判定）。

## 五、通过门槛（运行前登记）

以下全部满足方为通过：

| 项 | 门槛 | 依据 |
|---|---|---|
| 毛超额（对 B2 等权） | ≥ +2.0% 年化 | Q1 效应量推算：剔除底部 10% 约贡献 +0.22%/20日 ≈ +2.7% 年化，留 25% 余量 |
| 净超额（1× 成本） | ≥ +1.0% 年化 | 毛超额减成本后仍须显著为正 |
| 净超额（2× 成本） | > 0 | 成本翻倍下不死，是实盘可行性的最低证据 |
| 年度拆分 | 2024Q4、2025H1、2025H2 三段中至少两段净超额为正 | 防止单一 regime 驱动 |
| 最大回撤 | 相对 B2 等权基准的超额回撤不超过 5% | 剔除策略的尾部风险界限 |

不通过的处置：记录为冻结候选的最终经济否决，归档锁箱；**不调整剔除比例、不换打分模型、不改成本假设后重跑**。如需改任何一条，必须新一轮完整预注册（含因子层）。

## 六、必出报告项（描述性，不作判定）

1. 剔除名单的命中率分析：被剔除股票后续 20 日相对 B2 均值的平均超额（应与 Q1 诊断一致，约 -2%）。
2. 换手与容量：底部 10% 名单的日变更率、组合双边日换手率、按 ADV 估算的可承载资金量级。
3. A 轨附录：同一冻结分的 Top-5/Top-10/Top-20 扣费前后数字，仅入附录，不作任何判定与调参。
4. 剔除集中度：被剔除股票的行业/市值分布，检查是否系统性等同于"剔除小市值"（若是，需在报告中如实标注该策略与市值风格的不可分性）。

## 七、与既有纪律的衔接

- 本验收不触碰因子清单、标签定义、模型参数；任何这些东西的变更需求一律回描述阶段重新立项。
- 稳健性三件套（行业快照 PIT 敏感性、horizon 敏感性、2026-07-18 起前向数据的使用决策）在本验收通过后单独安排，其中 2026 年前向数据如使用须另行预声明单一假设。
- 开发者观察锁箱持续运行；本验收结果是是否推进 v6 官方锁箱评估的输入之一。
