# 因子精简与十分位诊断计划

日期：2026-08-20
状态：下一阶段执行计划；尚未产生新的因子冻结结论

本计划采纳 Kimi 对当前 158 个候选特征的建议，并遵守现有全市场范式。所有统计必须在全市场面板和新横截面标签上重算，不能沿用旧 events 域或旧 `EXRET20` 清单结论。

## 1. 预注册式三层消融

### 第一层：模型无关体检

只在 selection period 执行：

- 重算逐日 IC、日 rank 相关矩阵和 rolling IC 稳定性；复用 `bridge.factor_selection` 的现有函数，但输入必须是全市场面板与当前标签。
- 删除规则预先固定为：`|IC| < 0.01`；或注册方向与选择期证据冲突且人工决定不翻转；或日 rank 相关 `|rho| > 0.8` 的冗余对按 IC 优先保留一个。
- 这一层只生成候选清单，不直接改生产配置。

`|IC| < 0.01` 可能误删只有条件增量、没有单因子边际 IC 的特征，这是本方案接受的压缩取舍。若要保留此类例外，必须在看消融结果之前登记例外名单和因果假设，禁止结果出来后逐个“救回”。`factor_selection.py` 在实施前还必须把旧的默认 panel/`EXRET20` 常量改成显式的全市场 panel、universe 和 target 参数，并拒绝把 `panel_scope=events` 当成本轮输入。

### 第二层：整组 leave-one-family-out

以 `family_of()` 和 `info_type_of()` 的族定义分别做整组移除。两套分组是交叉视角，不把它们混成一套互斥族；运行前先输出 grouping manifest，人工检查 `info_type_of()` 的关键词归类，避免表达式因关键词顺序被错分。主线固定为：

- Huber 回归 + 原始相对收益秩；
- B2 中性残差秩 LambdaRank。

每个族只允许改变“是否移除该族”这一个变量。每组记录日均 IC、HAC IC_IR、折间 IC 标准差和相对完整集的变化。比较必须在同一 fold、同一 seed 上做配对差值；噪声带使用预先登记的 3 个种子 × 3 折配对 IC 差标准差，不在结果出来后调整阈值。只有两条主线都未出现超过噪声带的退化时，该族才进入删除候选；任一主线显示稳定增量则保留并记录模型依赖性。

### 第三层：幸存族组内贪心

只对第二层幸存族执行，优先使用按日期块/截面置乱的 permutation importance，避免随机打散单行破坏时间和截面结构；SHAP 只作归因交叉检查。从尾部每次删除 20%，直到 HAC IC_IR 跌破预先登记的噪声带。禁止对 158 个因子逐个 leave-one-out 硬磨。

每轮结果写入独立的 `runs/factor_selection_v3_<stage>/` 目录；候选清单和人工确认写入配置并单独提交。消融只能使用 selection period，清单冻结后在 evaluation period 一次性验证，不回看 evaluation 结果迭代。

## 2. 十分位诊断

十分位结果统一标记为 `post_hoc_descriptive_only`，只用于设计下一轮预注册实验，不直接增删因子。

### A. 截面十分位单调性

冻结模型使用严格折外预测生成每日预测分，按对应 universe 分成十组，输出每组平均 `y_excess20`、平均真实秩、市值/行业/动量暴露，以及 Q1 到 Q10 的单调性、Q10-Q1 HAC t 值。预测落盘至少包含 `date/code/fold/universe/target/prediction/y_excess20`，不得混入训练内预测。重点检查收益来自 Q10 还是主要来自 Q1 的剔除端；Q9/Q10 反超或 Q10 塌陷时，优先检查涨跌停、流动性和标签域定义。

### B. 时间维度 IC 衰减

同一冻结预测分分别对 1、5、10、20、40 日超额收益计算 IC，输出 IC(horizon) 曲线。若峰值明显早于 20 日，下一步只预注册 horizon/标签候选，不用该描述性结果直接重选因子。

## 3. 选择纪律

- 方向不自动翻转；方向改变、市场风格变化或频繁换向的因子保留人工审阅标记。
- 选择期只产生候选，evaluation 只做一次验证。
- Top-K、十分位和风格归因在筛选期均为辅助或描述性证据，不能反向修改当轮候选。
- 因子精简完成前，不进入新的 Top-K 专精验收。
