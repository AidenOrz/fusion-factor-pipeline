# PROJECT — Fusion Factor Pipeline 项目长期依据

> 更新时间：2026-09-01
> 依据：用户拍板与已执行的工程结果。

## 1. 项目目标与边界

目标：把 QuantGPT（表达式挖矿）、aurumq-rl（因子库与工程件）、a-share-factor-engine-v6（事件门、基准、锁箱纪律）组装为可复现、防过拟合的 A 股 Top-K 选股流水线。

边界：

- 不是实盘交易系统；不做券商下单。
- `2023-06-01..2024-09-12` 的选择期已经消费；`2024-10-22..2025-12-31` 的 B2 一次性内部历史留出也已于 2026-08-28 消费。二者都不是干净 OOS，结果不得回传修改本轮因子池、方向、标签或验收轨。
- v6 的 `2026-01-01..2026-07-17` M8 OOS 已永久消费；本项目可用于未来独立前向验证的干净数据自 2026-07-18 起算。

## 2. 已批准的关键决策

1. **验收基准 = 跑赢上证指数（000001.SH）**。legacy_score 因历史回测引擎记账问题只作诊断参照，不作硬门槛。
   **取代记录（2026-08-28）：** 随项目定位从 Top-K 全市场选股转为 B2 域 C 轨剔除，验收硬基准改为 B2 域等权（机制层）+ 中证 1000/中证 2000（机会成本层）；上证指数降为纯附录描述，不再承担任何门槛职能。原门槛保留为历史依据，不追溯改写旧实验。
2. **锁箱语义**：官方 v6 锁箱保持单次揭盲；本项目开发者观察锁箱允许无限次 `observe`，`formal-reveal` 每 epoch 一次。锁箱通过只表示“进入前向观察”，不等于 alpha 验证。
3. **数据口径**：v6 CSV 为前复权；桥接层统一 baostock 前复权数据；volume 统一为股；vwap=amount/volume；市值=close×总股本（baostock `totalShare`，按 `pubDate` as-of）。
4. **因子生产**：模型只生成表达式文本，收益由本项目判官评估。DeepSeek 当前可用模型为 `deepseek-v4-flash` 与 `deepseek-v4-pro`；支持 openai/anthropic provider。
5. **主判官**：lightgbm `LGBMRegressor` + purged walk-forward（20 日标签对应 gap≥20 个交易日）；筛选/消融期主看按日截面 IC、NDCG、HAC IC_IR 和折间一致性。当前冻结候选的经济验收主轨为 C 轨（剔除预测底部 10%），A 轨 Top-K 只作附录。
6. **RL 不进主判官**；aurumq-rl 的 PPO/A2C/SAC 保留为外部研究。
7. **C 轨验收的有限追认例外（2026-09-01）**：用户明确授权“已证明未实现原始预注册机械规则的实现 bug 运行不消费一次性验收”。该例外仅适用于 2026-08-28 C 轨的两个错误资金分母结果，不能用于更换因子、方向、模型、标签、成本、基准、持有期、剔除比例或成交规则，也不构成未来重跑历史验收的通用许可。最终 `325f458` 运行被追认为有效内部历史经济验收通过；完整依据见 `docs/WORK_REPORT_2026-09-01_C_TRACK_ACCEPTANCE_ADJUDICATION.md`，且 `production_authorized=false` 保持不变。

## 4. 长期约束

- 上游代码版本、数据快照、因子表达式和训练脚本都必须可哈希复现。
- 行业历史 PIT 免费源不可得；当前只有快照，使用必须标注 `snapshot_not_historical`。
- 不得把 live 状态回填历史面板；Top-K 必须落在可成交集合（停牌/ST/新股/涨跌停）。
- 每次“挖→算→训→验”为一次完整实验；OOS 结果不回传调参。
- 新的生产候选必须在 2026-07-18 后干净数据上同时通过：B2 域 C 轨机制门槛；并登记中证 1000/2000 及 50/50 混合的机会成本结果，其中 50/50 混合净超额 `> 0` 为次级判定；同时满足工程完整 + R 分布未退化。上证指数仅作附录描述。
- 前向观察前必须将目标 horizon 与 purged gap 绑定，并以真实交易日历验证 selection/evaluation 净空；不能依赖人工在日期间留缝。
