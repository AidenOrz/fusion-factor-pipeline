## 1. 设计原则（为什么这样定）

1. **外生规则优先**：域阈值交给外部机构（中证指数公司 2016 年公布的调样规则），而非从数据/资金反推——宣布"这个域不是我调出来的"。
2. **PIT 安全**：主域构成在 t 日只能用 t 日之前已知的信息；当前成分回填历史 = 生存者偏差（详见 §3.1）。
3. **标签同质性**：主板（±10%）与创业板/科创板（±20%）涨跌停制度不同 → EXRET20 截面方差按板块分层；混入同一截面排序会把"板块"学成隐因子，头部被高波动票占据（波动率暴露而非 alpha）。**主板是主线**。
4. **可对标**：域与公开指数对齐，基准用公开指数点位（无 PIT 问题），堵住"域内等权基准自我对冲掩盖偏差"的口子。

## 2. 三档域定义

| 档      | 定义                                | 实测规模                   | 角色           |
| ------ | --------------------------------- | ---------------------- | ------------ |
| **B1** | 全 panel（沪深主板，剔 ST/上市<1年）          | ~3,100 只/日             | 对照基线         |
| **B2** | t 日全市场流通市值排名 801~3800 ∩ 主板 ∩ panel | 约 1,700~2,000 只 | 中小盘          |
| **B3** | t 日全市场流通市值排名 1801~3800 ∩ 主板 ∩ panel | 约 1,000~1,200 只 | 聚焦域（小盘/微盘） |

**梯度设计目的**：比较 B1/B2/B3 的信号质量和稳定性；不预设 IC 随域收窄单调上升。

**规则细节**：

- 对照成分时点：2026-08-18（akshare 中证官网接口），存 `data/_c1000.csv` / `data/_c2000.csv`
- 主域排名：每个交易日基于全市场 `s1_mc_panel.parquet` 的 t 日流通市值排序；排名先在全市场完成，再与主板面板相交。
- 主板判定：code 前缀 `60/00/001/002/003`
- 每日过滤：非 ST（按 t 日名称）、上市满 1 年、t 日有交易
- **本轮基线流动性下限（2026-08-20）**：`ADV20 ≥ 200 万元`（过去 20 交易日日均成交额，t 日可得信息）
  - 推导：10 万全仓 ÷ Top-10 = 单笔 1 万；线性模型 0.5% 冲击上限 → 200 万；平方根冲击模型交叉验证（σ=2% → 16 万，σ=3%/0.3% → 100 万），取保守线性值
  - 实测（2023-06~2025-12 全期）：三域无一只股票日均 ADV < 1,196 万（B1 最低）/ 3,480 万（B3 最低）——**该阈值纯防御，不构成实际筛选**，仅挡极端日流动性枯竭/停牌僵尸股
  - 细节数据见 §4 附录（2026-08-20 段）

**基准**：B2/B3 用对应公开指数（中证 1000/2000 指数点位，或主板子集口径，S1 验证后定）；**不用域内等权**。

## 3. PIT 策略

### 3.1 生存者偏差警告（本方案的死穴，务必理解）

**现状风险**：对照 v1 用 2026-08 成分回填 2023-2025 历史。当前仍在成分里的公司 = 过去两年**没退市、没 ST、市值没掉出下限的幸存者**——用未来信息筛掉了输家 → **IC 假性飙升，且筛选期指标（IC 漂亮、折间一致好）完全看不出来**。

中证半年调一次（6月/12月），2023-06~2025-12 共 5-6 次调样，累计成分变动 ~30-40%。**偏差量级不可忽略。**

### 3.2 v1 策略（仅对照）：成分∩面板 + 敏感性检验

- 承认 PIT 成分偏差存在
- 重合率只能说明两个域定义接近，不能证明二者的收益、ST 或退市风险偏差很小；必须补充差异集的收益和状态检验。
- 所有对照结论必须标注"成分时点 2026-08-18，PIT 偏差未完全消除"；不得把 v1 作为主训练域。

### 3.3 v2 策略（主研究域）：复刻中证规则（逐日 PIT 安全）

**市值数据方案（2026-08-19 实测确认）**：baostock `query_history_k_data_plus` 返回 `turn`（换手率%）字段 → 反推逐日流通市值：

```
流通市值(t) ≈ close(t) × volume(t) / (turn(t)/100)
```

- 实测验证：浦发银行 2024-06 反推流通股本 293 亿股，与真实值一致
- 同接口附带 `isST`（每日 ST 状态，解决 S1 #4）与 `ipoDate/outDate`（上市时长）
- 全历史逐日可得，批量 3000+ 只约小时级，无需付费积分
- **口径注意**：反推为流通市值，中证规则用总市值——成熟公司（限售股少）误差小；次新股/高比例限售公司差异大，复刻时标注或用财务接口总股本校正

每半年（6月末/12月末）用 t 时点可见数据：

```
① 全市场按总市值降序（剔除上市<6个月、ST）
② 剔除前 800 名（上界 = 剔中证800）
③ 取第 801~3800 名（下界 = 剔微盘/流动性尾部）
④ 缓冲区：已在域内的放宽到 4200 名才剔除
```

- 主域 PIT 安全是**构造出来的**（全用 t 时点前数据），不依赖外部名单时点正确性
- 排名边界（800/3800/4200）是中证公布的规则参数 → 仍为外生
- 不受中证 2000 发布日（2023-08-11）限制，panel 起点 2023-06 全覆盖

### 3.4 S1 #2 PIT 敏感性检验结果（2026-08-19 完成）

**方法**：全市场 4,738 只沪深股票市值（baostock turn 反推），在 6 个中证调样日严格复刻排名规则（801~3800）→ ∩ 主板，与成分域对比。

| 检验             | 结果                                       | 判定                                          |
| -------------- | ---------------------------------------- | ------------------------------------------- |
| B'. 复刻域 vs 成分域 | **83.5% → 89.7%**（随时间收敛，2025-12 为 88.6%） | 两域高度一致；剩余 10-17% = 中证细则（行业均衡/ESG/缓冲区），非 PIT |
| A'. 复刻域时序漂移    | 83.6%（2023-06 → 2025-12）                 | 市值域 2.5 年自然变动 ~16%，正常                       |
| C'. 成分域回填偏差    | **83.5%**（2026-08 成分 vs 2023-06 复刻域）     | 回填历史偏差 ~16.5%，中等                            |

**结论**：

1. PIT 偏差真实且不能仅凭 16.5% 的重合差异定量为可控；差异集是否富集退市、ST 或极端亏损股票仍需单独检验。
2. **v1 成分回填域只作对照**，所有结果必须标注"成分时点 2026-08-18，PIT 回填偏差未消除"，不得作为主训练域或主结论依据。
3. **v2 复刻规则是主研究域候选**：它使用 t 时点可见输入构造；v1 保留用于公开指数口径的敏感性与可对标性检查。

### 4.1 流动性下限评估（2026-08-20）

**步骤 A 资金约束推导**（10 万全仓，Top-10 → 单笔 1 万）：

| 模型      | 公式                  | 冲击假设         | 阈值            |
| ------- | ------------------- | ------------ | ------------- |
| 线性占比    | ADV ≥ 单笔÷冲击         | 0.5% / 1%    | 200 万 / 100 万 |
| 平方根冲击   | Impact=c·σ·√(Q/ADV) | σ=2%, 冲击0.5% | 16 万          |
| 平方根（保守） | 同上                  | σ=3%, 冲击0.3% | 100 万         |

**步骤 B 域内 ADV 体检**（`s1_mc_panel.parquet`，成交额=close×volume）：

| 域                 | 2025 评估期日均 ADV P1 | 全期(23-06~25-12) P1 | 全期最低    | ADV<1000万 |
| ----------------- | ----------------- | ------------------ | ------- | --------- |
| B1 全市场            | 3,336 万           | 2,917 万            | 1,196 万 | 0 只       |
| B2 (1000∪2000)∩主板 | 5,847 万           | 4,577 万            | 3,480 万 | 0 只       |
| B3 中证2000∩主板      | 5,578 万           | 4,348 万            | 3,480 万 | 0 只       |

- 逐日检查（2025 全年 239 天）：ADV20<200 万 占比恒为 0.00%
- 200 万阈值下域规模损失：B3 1,080→1,072（-0.7%）

**步骤 C 经济性**：最差股（B3 全期最低 3,480 万）单笔 1 万占比 0.029%，平方根冲击 ≈0.11%，相对 20 日超额（1~2%）占比 <10%，可忽略。

**结论**：10 万资金在主板域内流动性零约束；`ADV20 ≥ 200 万` 为纯防御条款。
