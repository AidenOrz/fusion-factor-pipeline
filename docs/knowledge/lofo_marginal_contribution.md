# LOFO 边际贡献判读

## 适用场景

全市场横截面因子池的预注册整组消融。使用同一模型、相同 purged folds 和种子，仅改变移除的因子组。

## 已验证洞见

- 单因子 IC 强、方向稳定或与其他因子低相关，不等于它在模型内有正的边际贡献。
- 例如 `alpha_qg_corr_pv_10` short 版本在单因子选择期 IC 约为 -0.053、一致性约 1.0，但作为 `starter` 成员移除后两条 Huber 主线均在噪声带内；其信息可能已被其余 correlation 因子覆盖。
- 因此“单因子有效性”和“模型内增量价值”必须分开登记：前者用于候选解释，后者由预注册 LOFO 与剪后确认决定。

## 推荐做法

- `delta_ic > noise_std` 表示移除后变好，组的模型边际贡献为负；不能机械写成保留。
- `delta_ic < -noise_std` 表示移除后变差，组有正边际贡献，应保留。
- 带内只表示当前样本无法检测边际贡献，不是因子必然无效。
- 各组 LOFO 的改善幅度不可相加；只有联合剪后确认实验可以估计组合后的真实水平。
- 人工已批准的方向变换因子必须在组内剪枝时显式豁免，并记录豁免理由，不能由所属信息类型的整体结论覆盖。

## 证据边界

上述结论来自 `runs/factor_ablation_v4_b2_huber_cross_label_2026-08-28/` 的 selection-only 结果，分类为 `post_hoc_descriptive_only`，不直接改写候选配置，也不构成 evaluation 或生产批准。
