### 节点 14：聚焦排序器怎么做 + 中性化风险

**触发**：用户回应——中性残差有风险、并行研究行业/风格层可以做、问聚焦排序器怎么做。

**风险接住**（三层）：
1. 中性化剔除可交易真钱（小市值风格）→ 保留市值特征对照版
2. 行业内集中（行业 alpha 伪装成个股 alpha）→ 输出层行业分散约束

**聚焦域三层结构**：
```
第 0 层 域定义：市值分位<30% + 流动性下限 + 非 ST/退市风险
第 1 层 域内排序：LambdaRank on 中性残差秩（反转/低波/区间收缩特征）
第 2 层 风格叠加：第二支柱接口（小盘/大盘择时 → 权重）
```

**评估口径变化**：聚焦版基准 = 聚焦域内等权组合（不是上证），跑赢域基准 + 中性残差为正 = 纯选股 alpha。
