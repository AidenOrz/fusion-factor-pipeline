# 前向观察预注册（2026-10-18，阶段 F 第 7 项）

> 机器可校验合约：`config/forward_observation_prereg_2026-10-18.json`
> 判读实现：`bridge/forward_evaluation.py`（拒绝在未登记状态下运行）
> 结论先行：**协议已登记，首次判读为 EXPLORATORY（39 < 40 个可用标签日）**，不构成通过或否决。

## 1. 为什么需要这份文件

前向观察的风险不在"看数据"，而在**看到数据后再决定怎么看**。冻结配置已经把因子、标签、
模型固定下来，但没有固定"用什么指标判定、用什么阈值、什么时候停"。没有这一层，
一次不理想的 IC 可以被解释成"窗口太短"，一次漂亮的 IC 也可以被直接当成通过。

本文件在**任何前向 IC 被计算之前**把这些固定下来，并由代码强制：`bridge/forward_evaluation.py`
读取 `status == "registered_before_results"` 才肯运行。

## 2. 观察对象与窗口

| 项 | 值 |
|---|---|
| 评分模型 | `huber_b2_neutral_rank`（冻结配置按 id 选取，不靠位置） |
| 特征 | 37 个冻结特征 |
| 标签 | `y_neutral_rank20_b2`，20 个交易日 |
| 训练 | 选择期 2023-06-30~2024-09-12 **只训练一次**，前向期不更新 |
| 观察窗口 | 2026-07-20 ~ 2026-10-16（59 个交易日） |
| 其中可算标签 | **39 个交易日**（2026-07-20 ~ 2026-09-10） |
| 剔除比例 | 底部 10% |

标签日少于窗口日的 20 天差额**不是数据缺口**：20 日标签要求未来 20 个交易日行情，
窗口最后 20 天在结构上不可能有标签。这是前瞻标签的固有边界。

## 3. 指标（在结果已知前固定）

**主指标**：日度 Spearman IC（预测值 vs `y_excess20`，B2 域内），要求每日至少 500 只、
两侧至少 5 个不同取值，否则该日剔除并计数；再取算术平均。

**次指标**：

1. IC 胜率（IC > 0 的交易日占比）
2. HAC IC_IR（Newey-West，滞后 20）——**在 250 个标签日之前只报告、不作决策输入**
3. 底部剔除名单换手率：`|今日剔除 ∩ 昨日剔除| / |昨日剔除|`
4. 剔除组前向超额：剔除组 `y_excess20` 均值 − 全截面均值，预期为负
5. 行业暴露稳定性：快照列与 SW2021 PIT 列**各自**报告
6. 评分分布漂移：逐日均值与标准差

## 4. 判定规则

| 判定 | 规则 | 含义 |
|---|---|---|
| **PASS_CONTINUE** | IC 均值 > 0 **且** ≥ 0.06265（评价期 0.1253 的一半）**且** 胜率 ≥ 50% **且** 前后半窗同号 | 与冻结评价一致，继续观察 |
| **INCONCLUSIVE** | 不满足 PASS，也未触发中止 | 继续观察，**不得**改动冻结配置 |
| **HALT** | IC ≤ 0；或 IC < −0.06265；或某日 B2 不足 500 只；或非有限预测 > 0.5%；或日评分均值越出 [0.40, 0.60]；或日评分标准差越出 [0.02, 0.10]；或 |IC| > 0.40 | 停线诊断。**HALT 不是因子失败的证据**，而是观察环境不可信 |
| **EXPLORATORY** | 标签日 < 40 | 样本不足，一律不得给出通过/否决 |

**观察期禁止动作**（写入合约，逐条列出）：改因子清单、改标签定义或 horizon、改剔除比例、
改超参或种子、用任何前向数据再训练、用前向结果选因子、因某日 IC 不利而删除该日。

**晋级门槛**：≥ 250 个标签日 + PASS_CONTINUE + 剔除组超额为负且前后半窗稳定 +
换手率与历史 C 轨一致 + 无未解释的中止；届时另立 v6 官方锁箱的单独预注册（单次揭盲语义不变）。

## 5. 必须自我披露的一点

写这份协议时，**可用标签日的数量（39）已经可见**——它由数据地平线和 20 日标签直接决定，
不是看到 IC 之后才知道的。但 **IC 值当时未知**。

这带来一个必须写明的后果：把门槛设在 40，恰好比可见的 39 高一点点。读者有权知道这个数字关系，
所以我把它写进合约（`disclosure_sample_size_was_visible`），并同时锁定：**该阈值不得在事后为
迎合新样本而调整**，首次判读只能按规则落到 EXPLORATORY，而不是靠判断力"通融一下"。

## 6. 首次判读结果（EXPLORATORY，非结论）

| 指标 | 值 |
|---|---|
| 可用标签日 | 39（剔除 20 天） |
| 日 IC 均值 | **0.12689** |
| IC 标准差 | 0.11821 |
| IC 胜率 | **82.05%** |
| HAC IC_IR | 0.7559（样本过小，仅报告） |
| 前半窗均值 | 0.08269 |
| 后半窗均值 | 0.16888 |
| 接缝前（07-20~07-24） | 0.08135（5 天） |
| 接缝后 | 0.13358（34 天） |
| 剔除组前向超额 | **−2.251%**（符合预期方向） |
| 剔除组超额为正的天数占比 | 12.82% |
| 底部名单换手率 | 0.5267 |
| 日评分均值范围 | 0.4903 ~ 0.5054 |
| 日评分标准差范围 | 0.0444 ~ 0.0614 |

四项 PASS 条件**全部满足**，七项 HALT 条件**全部未触发**——但因为只有 39 个标签日，
按预注册规则**强制判为 EXPLORATORY**。这正是协议存在的意义：数字好看也不能越过样本量门槛。

**必须同时声明的局限**：39 个标签日、20 日重叠标签，相邻日 IC 高度自相关，有效独立样本约 2 个。
HAC IC_IR 的 0.7559 在这个样本量下**不具解释力**，不得引用为"IR 很高"。
